# DEAD SIGNAL v0.0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first playable browser prototype of DEAD SIGNAL where the player sees a settlement, spends Metal to construct a Generator, hears a building-linked audio layer, sees a minimal future-facing hex preview, and keeps the same state after reload.

**Architecture:** Use a small React + TypeScript browser app with domain logic isolated from UI, local persistence for v0.0.1, and data-driven definitions for buildings/resources. Keep the global strategy systems out of runtime behavior for this milestone while preserving clean extension points for future hex, faction, survival, and army modules. Replit is the initial build environment; GitHub is the canonical source once a dedicated DEAD-SIGNAL repository is created; Vercel can host previews later.

**Tech Stack:** React, TypeScript, Vite, Vitest, React Testing Library, browser localStorage, Web Audio / HTMLAudioElement-compatible abstraction, CSS responsive layout.

**Spec:** `docs/superpowers/specs/2026-09-11-dead-signal-foundation-design.md`

## Global Constraints

- Original DEAD SIGNAL IP; do not copy protected names, art, text, audio, UI, or lore from existing games.
- Web-first and usable in Meta Quest 2 browser, iPhone-sized screens, and desktop browsers.
- v0.0.1 uses local persistence only; Supabase is not a runtime dependency for this milestone.
- One settlement scene only; no PvP, alliances, multiplayer world, crypto, real-money monetization, diplomacy, army combat, logistics simulation, faith simulation, radiation damage simulation, temperature survival simulation, live events, hero roster, or app-store packaging.
- Client renders only the active prototype scene.
- Gameplay definitions and runtime state remain separate.
- Audio failure must never block gameplay.
- Corrupt local saves must fall back to a clean initial state with a visible reset control.
- First milestone proves one generator build action and one dynamic audio layer.
- Future world-map support uses axial hex coordinates (`q`, `r`).

```ts
export type ResourceId = 'metal' | 'food' | 'power' | 'people';
export type ResourceState = Record<ResourceId, number>;
export type ResourceCost = Partial<Record<ResourceId, number>>;

export function canAfford(resources: ResourceState, cost: ResourceCost): boolean {
  return Object.entries(cost).every(([id, amount]) =>
    resources[id as ResourceId] >= (amount ?? 0),
  );
}

export function spendResources(resources: ResourceState, cost: ResourceCost): ResourceState {
  if (!canAfford(resources, cost)) return resources;
  return Object.fromEntries(
    Object.entries(resources).map(([id, amount]) => [
      id,
      amount - (cost[id as ResourceId] ?? 0),
    ]),
  ) as ResourceState;
}
```

- [ ] **Step 1: Write failing persistence tests**

```ts
import { describe, expect, it } from 'vitest';
import { createInitialGameState } from '../domain/gameState';
import { loadGame, resetGame, saveGame } from './saveStore';

function memoryStorage(): Storage {
  const values = new Map<string, string>();
  return {
    get length() { return values.size; },
    clear: () => values.clear(),
    getItem: key => values.get(key) ?? null,
    key: index => [...values.keys()][index] ?? null,
    removeItem: key => values.delete(key),
    setItem: (key, value) => values.set(key, value),
  } as Storage;
}

describe('saveStore', () => {
  it('round-trips game state', () => {
    const storage = memoryStorage();
    const state = createInitialGameState();
    saveGame(storage, state);
    expect(loadGame(storage)).toEqual(state);
  });

  it('falls back to initial state on corrupt JSON', () => {
    const storage = memoryStorage();
    storage.setItem('dead-signal:v1', '{broken');
    expect(loadGame(storage)).toEqual(createInitialGameState());
  });

  it('reset removes save and returns clean state', () => {
    const storage = memoryStorage();
    saveGame(storage, createInitialGameState());
    expect(resetGame(storage)).toEqual(createInitialGameState());
    expect(storage.getItem('dead-signal:v1')).toBeNull();
  });
});
```
